# Security policy

Report a security issue privately through GitHub's **Report a vulnerability** option for this repository if it is available. If that option is unavailable, contact the repository owner through their GitHub profile to request a private reporting channel. Do not include exploit details or secrets in a public issue.

Do not send production access tokens, webhook secrets, customer records, or payment credentials in a report. A minimal reproduction using fictional data and the affected commit is sufficient.

The supported code is the current default branch. Security changes under review in a pull request are not considered released.
